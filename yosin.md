# Техническое задание: Ёсин (Yosin)

## Роль и задачи
Ты отвечаешь за безопасность (Авторизация и Регистрация) и коммуникацию пользователей (Личные сообщения / Direct / Chat). 

## Детальный план работ

### 1. Авторизация и Регистрация (Auth)
- [ ] Верстка страницы Входа (Login Page) в стиле Instagram.
- [ ] Верстка страницы Регистрации (Register Page).
- [ ] Управление формами с помощью React Hook Form.
- [ ] Добавление строгой валидации (Zod или Yup):
  - Проверка длины пароля, формата email, уникальности username.
  - Отображение понятных сообщений об ошибках под полями ввода.
- [ ] Визуальные состояния кнопок (отключение при загрузке (isLoading), спиннер).

### 2. Интеграция API Авторизации (RTK Query)
- [ ] Создание `authApi` с мутациями `login` и `register`.
- [ ] Управление JWT токенами: сохранение токена в `localStorage` (или куки) после успешного логина.
- [ ] Разработка компонента `ProtectedRoute` или логики Middleware (в Next.js) для перенаправления неавторизованных пользователей на страницу логина при попытке зайти на закрытые страницы (Лента, Профиль).
- [ ] Реализация функционала "Выйти" (Logout) с очисткой токенов и глобального стейта.

### 3. Личные сообщения (Direct / Chat)
- [ ] Разработка макета раздела сообщений:
  - Левая колонка (Inbox): Список последних диалогов (имя пользователя, последнее сообщение, время, индикатор непрочитанных).
  - Правая колонка (Chat Room): Само окно переписки. Если диалог не выбран — красивое пустое состояние (Empty State) "Ваши сообщения".
- [ ] Внутренности окна чата:
  - Шапка с именем собеседника.
  - Область истории сообщений (скролл вниз по умолчанию).
  - Поле ввода (Textarea, которая расширяется по мере набора текста) и кнопка отправки.
- [ ] Разработка RTK Query эндпоинтов:
  - `getConversations` (список диалогов).
  - `getMessages` (история сообщений по конкретному chatID).
  - `sendMessage` (отправка сообщения).
- [ ] *Дополнительно (на будущее)*: Заложить архитектуру стейта так, чтобы позже легко подключить WebSockets (например, Socket.io) для получения сообщений в реальном времени.
