# Техническое задание: Идибой (Idiboy)

## Роль и задачи
Твоя главная зона ответственности — раздел "Reels" (короткие видео). Это одна из самых сложных частей UI, требующая плавных анимаций, хорошей оптимизации плеера и удобного скролла.

## Детальный план работ

### 1. UI и Компоненты Reels
- [ ] Разработка основного контейнера страницы Reels (полноэкранный режим без стандартного Sidebar на мобильных, или с ним на десктопе).
- [ ] Создание компонента `ReelCard` (занимает 100% высоты и ширины экрана/контейнера).
- [ ] Разработка кастомного видеоплеера:
  - Скрытие стандартных контролов браузера.
  - Воспроизведение/пауза при клике в центр экрана (с иконкой плей/пауза, которая плавно исчезает).
  - Кнопка включения/отключения звука (Mute/Unmute).
- [ ] Верстка UI-оверлея (поверх видео):
  - Нижний левый угол: Аватар, Username (с кнопкой подписки), описание видео (с раскрытием текста), бегущая строка музыки.
  - Правый нижний край: Иконки взаимодействия (Лайк, Комментарий, Поделиться, Оригинальный звук) с цифрами-счетчиками под ними.

### 2. Логика и Взаимодействие (RTK Query)
- [ ] Настройка среза API `reelsApi` в RTK Query.
- [ ] Реализация запроса `getReels` для получения массива видео.
- [ ] Реализация механизма перелистывания (Snap Scrolling): при скролле следующее видео должно четко фиксироваться на экране.
- [ ] **Сложная логика**: Авто-воспроизведение только того видео, которое сейчас в зоне видимости (использование `IntersectionObserver`), и постановка на паузу остальных.

### 3. Функции вовлечения (Engagement)
- [ ] Анимация "Лайка": при двойном тапе по видео в центре экрана появляется и плавно исчезает большое сердечко.
- [ ] Интеграция мутаций `likeReel` и `unlikeReel`. Оптимистичное обновление UI для счетчика лайков.
