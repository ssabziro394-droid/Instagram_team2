# Техническое задание: Идибой (Idiboy)

## Зона ответственности
Раздел Explore Reels (вертикальная прокрутка видеороликов).

## Ваши закрепленные файлы и папки
Чтобы избежать конфликтов слияния, вы работаете **только** в следующих локациях:
- **Маршруты (Pages)**:
  - `app/(root)/reels/page.tsx` (Страница Reels)
- **Компоненты (Components)**:
  - `components/reels/*` (Видеоплеер Reels, оверлеи кнопок, комментарии к Reels)
- **API и Стейт (Redux)**:
  - `store/api/reelsApi.ts` (Все эндпоинты для Reels через `baseApi.injectEndpoints`)

## Детальный план работ

### 1. Верстка плеера Reels
- Создать в `components/reels/` компоненты `ReelPlayer.tsx` и `ReelOverlay.tsx`.
- Настроить полноэкранный контейнер для мобильных устройств.
- Настроить кастомные кнопки паузы и звука.

### 2. Запросы и Логика
- В `store/api/reelsApi.ts` реализовать эндпоинты:
  - `getReels` (получение списка видеороликов)
  - `likeReel` (мутация лайка)
- Настроить `IntersectionObserver` в React для отслеживания видимого на экране видеоролика, чтобы запускать только его.

### 3. Интеграция
- Добавить список Reels на страницу `app/(root)/reels/page.tsx`.
