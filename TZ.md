# Техническое Задание (ТЗ) — Клон Instagram

## 1. Описание проекта
Проект представляет собой полноценное веб-приложение — клон Instagram, реализующее основные функции социальной сети: регистрация/авторизация, лента новостей, публикация постов и коротких видео (Reels), поиск пользователей, просмотр профилей и личные сообщения (Chat).

## 2. Технологический стек
- **Frontend**: Next.js (App Router, Server & Client Components) / React
- **Управление состоянием и API**: Redux Toolkit (RTK) и RTK Query для кэширования и запросов
- **Стилизация**: Tailwind CSS (с использованием модулей или styled-components по необходимости, но предпочтительно чистый Tailwind)
- **Формы и Валидация**: React Hook Form + Zod / Yup
- **Иконки**: Lucide React / Heroicons
- **Анимации**: Framer Motion (для Reels, модальных окон, лайков)
- **Backend/API (Будущее/Текущее)**: MockAPI для старта, в дальнейшем Node.js/Express или Firebase/Supabase

## 4. Подробное описание функционала

### 4.1. Главная страница и Создание постов (Амирджон)
- **Лента новостей (Feed)**: Вывод постов пользователей, на которых подписан текущий пользователь. Отображение фото/видео, лайков, комментариев, времени публикации.
- **Интерфейс приложения**: Навигационное меню (Sidebar на десктопе, нижний TabBar на мобильных устройствах).
- **Создание контента**:
  - Загрузка фото для обычных постов с возможностью обрезки/фильтров (опционально) и добавлением описания (Caption).
  - Загрузка видео для Reels с превью.

### 4.2. Reels (Идибой)
- **Плеер Reels**: Вертикальный свайп, автоматическое воспроизведение при попадании в область видимости, пауза по клику.
- **Взаимодействие**: Кнопки лайка (с анимацией двойного тапа), комментариев и "поделиться", наложенные поверх видео.
- **Производительность**: Оптимизация загрузки видео, предварительная загрузка (preload) следующих роликов.

### 4.3. Авторизация и Сообщения (Ёсин)
- **Безопасность**: JWT-токены, хранение в `httpOnly cookies` или `localStorage`. Восстановление пароля (в перспективе).
- **Direct Messages**: 
  - Список диалогов (Inbox).
  - Окно чата (история сообщений, отправка текста/фото).
  - Управление состоянием прочитано/не прочитано.

### 4.4. Профиль и Поиск (Исмоил)
- **Профиль**: Шапка (Аватар, имя, био, счетчики подписчиков/подписок). Сетка постов, вкладки для обычных фото, Reels и сохраненных.
- **Подписки**: Логика подписки (Follow) и отписки (Unfollow).
- **Поиск**: Глобальный поиск по никнейму или имени с выпадающим списком (debounce для оптимизации запросов).

## 5. Процесс разработки (Git Flow)
- Ветка `main` — стабильный продакшен-код.
- Ветка `develop` — основная ветка разработки.
- Для каждой задачи создается отдельная ветка (например, `feature/auth-yosin`, `feature/reels-idiboy`).
- После выполнения задачи создается **Pull Request (PR)** в ветку `develop`, который проверяет Team Lead (Амирджон).
